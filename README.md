# Ark Color Tracker

A single-page color collection tracker for **ARK: Survival Ascended**.

Track tameable creatures, color IDs & dyes (per gender), custom combos, and ownership (Male / Female / Non-Breedable).

## Use it
- Live site (after enabling GitHub Pages): `https://YOUR_USERNAME.github.io/ark-color-tracker/`
- Or open `index.html` locally in any browser.

## Features
- Full tameable creature list (with variants)
- Color ID & dye checklist (1–100 + dyes 128–254)
- Male / Female / NB-NG tracking
- Custom color combos (R0–R5)
- Color ID search
- Progress saved in your browser (localStorage)

## GitHub Pages
1. Push this repo to GitHub.
2. Settings → Pages → Deploy from branch `main` → root.
3. Share the published URL.
